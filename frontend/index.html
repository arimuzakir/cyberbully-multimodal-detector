Panduan Pemasangan Ekstensi Browser

Ikuti 4 langkah mudah berikut untuk mengaktifkan deteksi real-time

1
Unduh & Ekstrak File

Klik tombol download di bawah dan ekstrak file cyberbully-extension.zip ke folder di komputer Anda.

2
Buka Halaman Ekstensi

Di Google Chrome / MS Edge / Brave, ketik di address bar: chrome://extensions atau edge://extensions.

3
Aktifkan Developer Mode

Nyalakan toggle Developer mode (Mode pengembang) di sudut kanan atas layar browser.

4
Load Unpacked

Klik tombol "Load unpacked" di kiri atas, lalu pilih folder ekstensi yang sudah diekstrak tadi. Selesai!

1
Download Kiwi Browser

Pasang Kiwi Browser atau Yandex Browser gratis dari Google Play Store.

2
Unduh ZIP Ekstensi

Download file cyberbully-extension.zip langsung melalui smartphone Anda.

3
Masuk Menu Ekstensi

Buka menu titik tiga di Kiwi Browser ➔ pilih Extensions ➔ aktifkan Developer Mode.

4
Muat File ZIP

Klik "+ (from .zip/.crx/.user.js)" dan pilih file zip yang sudah diunduh. Ekstensi siap memindai sosmed!
